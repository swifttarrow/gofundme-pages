The three pages (profile, fundraiser, community) are seamlessly integrated and intuitive.
Well instrumented; explain what metrics you'll capture and why.
Submissions will be graded on:
* Observability
* Simplicity
* Test coverage
* Documentation
* Run books
* Error handling
* Stateless
* Horizontally scalable
