# Community Page Spec

## Overview
A hub for cause-based communities where users can discover, engage, and donate to related fundraisers.

---

## Core Layout

### 1. Community Header
- Community name
- Cover image
- Description
- Follow / Join CTA

---

### 2. Featured Fundraisers
- Highlighted campaigns
- Carousel or grid
- Includes:
  - Title
  - Progress bar
  - Raised amount

---

### 3. Feed (Core Component)
- Mixed content feed:
  - Fundraisers
  - Updates
  - Announcements
- Each item includes:
  - Title
  - Media
  - Engagement (likes/comments optional)

---

### 4. Category / Tag System
- Filter by:
  - Urgent
  - Trending
  - Recent
  - Category (e.g. wildfire, medical)

---

### 5. Social Proof Layer
- Total funds raised (community-level)
- Number of supporters
- Activity indicators

---

### 6. Discovery Section
- Related communities
- Suggested causes
- Trending fundraisers

---

## Functional Requirements

### Feed Interaction
- Infinite scroll
- Sort/filter
- Click-through to fundraiser pages

### Community Actions
- Follow / unfollow
- Share community
- Save/bookmark fundraisers

---

## Non-Functional Requirements

- Fast feed rendering (<1.5s initial load)
- Real-time-ish updates (polling or streaming)
- Mobile-first scrolling UX

---

## Key Metrics

- DAU / MAU
- Fundraiser click-through rate
- Follow rate
- Donations originating from community
